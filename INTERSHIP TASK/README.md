# Week 1 – Strategic Planning and Data Exploration in Logistics

## Overview
A strategic planning report and Python notebook demonstrating logistics data exploration, KPI calculation, regression and clustering.

## Files
- `Week_1_Logistics_Strategic_Planning_Report.docx` – Word report.
- `notebooks/Week1_Logistics_Data_Exploration.ipynb` – Colab/Jupyter notebook.
- `dataset/logistics_sample_data.csv` – synthetic sample dataset.
- `REPORT_DESCRIPTION.txt` – description for the internship submission form.

## Run in Google Colab
1. Download and open the notebook at https://colab.research.google.com/.
2. Upload the notebook, then run cells from top to bottom.
3. When prompted, upload `dataset/logistics_sample_data.csv`.

## Methods
Pandas data cleaning, KPI calculation, Matplotlib visualization, linear regression (MAE/RMSE), and K-means clustering.

## Dataset limitation
The included CSV is synthetic demonstration data, not a public or company dataset. Its results are illustrative only. For a research-based final analysis, replace it with a suitable public dataset and document its source, license, coverage, and limitations.

## Submission
Upload the Word report separately to the internship portal. Provide this repository URL and a report description of at least 200 words.
