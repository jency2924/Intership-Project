This project focuses on data collection, cleaning, and preprocessing for logistics analysis using Python. The dataset is inspected to understand its structure, data types, missing values, duplicate records, and numerical statistics. Exact duplicate rows are removed, and date columns such as order date, actual delivery date, and promised date are converted into datetime format. Delivery duration is calculated in days to support delivery performance analysis.

The project uses the Interquartile Range (IQR) method to identify potential outliers in transportation distance, delivery duration, delivery cost, and unit cost. Min-Max normalization and Z-score standardization are applied to selected numerical features using Scikit-learn. A histogram is created using Matplotlib to visualize the distribution of delivery times. Finally, the processed dataset is verified and exported as a CSV file for further analysis.

This task demonstrates the importance of data quality in logistics operations. It provides practical experience with Pandas, NumPy, Matplotlib, and Scikit-learn and establishes a foundation for future logistics analytics, delivery performance evaluation, and supply chain decision-making.
