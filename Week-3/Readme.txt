# Week 3: Advanced Data Analysis and Visualization in Logistics

## Project Overview
This project analyzes a hypothetical logistics dataset using Python to understand delivery performance, shipment volumes, transportation costs, and regional logistics operations.

## Objectives
- Perform Exploratory Data Analysis (EDA).
- Calculate descriptive statistics and central tendencies.
- Examine data quality, distributions, and correlations.
- Analyze logistics KPIs such as average delivery time, transportation cost, and on-time delivery rate.
- Visualize logistics performance using a heatmap and two bar charts.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Analysis Performed
1. Dataset inspection and data quality checks.
2. Missing value and duplicate checks.
3. Statistical and distribution analysis.
4. Correlation and KPI analysis.
5. Visualization of delivery time by transport mode and transportation cost by region.

## Visualizations
- Correlation Heatmap of Logistics Metrics
- Average Delivery Time by Transport Mode
- Average Transportation Cost by Region

## Expected Outcome
The analysis helps compare logistics performance, understand relationships between numerical variables, identify potential cost differences, and support data-driven recommendations for improving delivery efficiency.

- Google Colab notebook containing Python code.
